Paste the refresh token from your Kiro IDE. Tokens from a real IDE session keep upstream from flagging the account as a bot, which is why this path is far more stable than browser OAuth.

Grab it from Kiro IDE's auth.json under ~/.aws/sso/cache, the IDE's DevTools, or the Session:Export command. Refresh tokens usually start with aorAAAAAG.

Fallback flow. Open the Kiro login URL, sign in, then paste the kiro://...?code=... URL the browser fails to redirect to.
